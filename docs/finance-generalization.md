# 财报泛化包（零样本跨域评测）

> 方法学：系统构建与调优仅基于学术论文语料（11 篇），财报包在构建期不可见——
> 属**零样本跨域评测**（BEIR 方法学，NeurIPS 2021 D&B [N7]）。域内→域外的指标降幅
> 如实报告，不做针对性调优。

## 1. 语料

3–5 篇 A 股上市公司年度报告 PDF（覆盖不同行业与版式）：

| # | 公司 | 年份 | 版式预检（OmniDocBench 维度） |
|---|---|---|---|
| 1 | （占位——下载后填） | | 文本层/表格边框/跨页表/合并单元格 |
| 2 | | | |
| 3 | | | |

## 2. 预检清单（OmniDocBench 难点维度 [N6]）

拿到每份 PDF 先查五项：
1. **有无文本层**（扫描件走 OCR，解析险）
2. **表格边框类型**（三线/无边框表最险）
3. **跨页表与合并单元格**所在页
4. **双栏/竖排/旋转版式**
5. **水印**

## 3. 题集

每篇 ≥10 题（表格数字题为主：营收/增速/占比/对比），构造方式与自建题集一致
（`doclens/eval/dataset.py` 出题管线，财报域复用）。

## 4. 验收线

- **解析层**：Markdown 表格人工抽查可读、跨页表合并正确
- **问答层**：可回答且引用页码点中正确 bbox；表格数字题 F1 如实报告
- **口径**：财报域指标 vs 论文域指标并列展示（降幅=泛化成本，如实呈现）
