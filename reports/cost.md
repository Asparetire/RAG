## 5. M2 实测记录（2026-11-11，随实施回填）

| 项目 | 数值 | 备注 |
|---|---|---|
| 索引单元规模 | **1513 单元**（text 857 + caption 202 + table 125 + image 329） | chunker 实测，比预估 2450 省 ~38%（聚合 + References 过滤 1202 块生效） |
| 文本嵌入首调 | 0.4s（2 条并发） | 二次同输入 0.02s **缓存全命中零 API 费**（2.3 验收） |

| E 档全量预估 | ~1513 块 → 约 70 分钟 | M5 按需生成（M2 只做 100 块试产） |
| 图像探针（调研 R4） | 33KB 图降采样 1024px → 余弦 0.9851 | 结论：**仅对长边 >1024px 的图降采样**，小图原样嵌入；大图对照留 2.7 探针 |
