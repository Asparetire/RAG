# DocLens 文档图表多模态 RAG PRD

> 状态：待确认 ｜ 阶段：S0 需求定义 ｜ 任务 slug：`doclens-multimodal-rag`
> 前置输入：本会话已完成的需求分析（功能清单/架构/选型/里程碑）与四项澄清答复（多方向求职均衡、本地演示+录屏、2–3 周业余、默认项全接受）

## 背景与目标

**背景**：作者求职 LLM 方向（具体岗位未定，算法 / 应用工程 / 后端转 AI 均在投），需要一个作品集项目，同时证明**多模态检索能力、端到端工程能力、演示完成度**——三线均衡，各有硬性产物。

**一句话定位**：输入一批 PDF 文档（论文，后期加财报），回答"必须看图看表才能答对"的问题，答案带可溯源引用，点击引用直达 PDF 原页并高亮对应图表区域。

**成功标准**：

| ID | 标准 | 度量 |
|---|---|---|
| S1 | 多模态增益量化 | 图表类问题检索 recall@5，full 配置 vs 纯文本 baseline 提升 ≥15 个百分点（目标值，以实测为准，须出对比表） |
| S2 | 演示流畅 | 完整问答演示流程（提问→流式回答→引用点击→原页高亮）≤20 秒 |
| S3 | 可复现 | 克隆仓库，按 README 两条命令（构建 + 启动）跑通全流程 |
| S4 | 文档完备 | README 含架构图、消融指标表、API 成本核算表 |

## 用户与场景

**用户**：
- 主要：面试官 / 技术评审（时间有限，10–15 分钟演示内要说得清、看得见、信得过；关注能力真实性与量化，不关注产品功能广度）
- 次要：作者本人（后续扩充语料、日常试用）

**典型查询场景**（语料为英文论文，提问用中文）：

| 类型 | 示例 | 评判要点 |
|---|---|---|
| 纯文本题 | "自注意力的复杂度是 O(n·d) 吗？" | 文本证据即可答对 |
| 图表题 | "成绩对比图里哪个考试上超过了人类考生？" | **不看图必答错**——多模态能力的核心证明 |
| 表格题 | "Table 2 里 7B 比 13B 在 MMLU 上低多少分？" | 必须读表格结构 |

**演示形态**：本地演示 + 录屏（不做公网部署，避免运维与持续成本）。

## 需求清单

### P0（本期必须交付）

| ID | 需求 | 验收标准 |
|---|---|---|
| R1 | **文档摄入与解析**：批量导入本地 PDF、增量解析（已解析跳过）；统一文档模型（段落/标题/表格/图片，带页码与区域坐标）；图注与图表绑定；表格保留结构并提供线性化文本 | 10 篇种子 PDF 解析成功；图注绑定率抽检 ≥90%；解析产物可检查、可缓存 |
| R2 | **多模态索引**：文本块（含图注、表格线性化）与图表图片分别入向量索引，另建关键词索引；元数据（文档/页码/类型/坐标/图片路径）完整；嵌入结果落盘缓存 | 抽查 10 个查询 top-5 基本相关（人工判定）；增量重建索引不产生重复 API 费用 |
| R3 | **混合检索与重排**：多路召回 → 融合 → 重排；消融配置开关（A 纯文本 / B +图注文本 / C +图像检索 / D +重排） | 一条命令切换配置并重跑评测；A–D 产出可对比指标 |
| R4 | **带据生成**：回答带引用标注；引用映射到文档+页+区域；无依据兜底（检索置信不足时明确说明，不编造） | 20 个冒烟问题人工通过率 ≥80%；引用点击均指向正确原页 |
| R5 | **演示 UI**：对话 + 流式输出 + 引用侧栏 + 点击引用 → PDF 原页渲染 + 区域高亮 | 完整演示流程 ≤20 秒（不含网络抖动） |
| R6 | **评测与消融**：约 150 题（纯文本/图表/表格 各 50），半自动出题 + 人工审核；指标覆盖检索（recall@k / MRR / nDCG）、答案质量（双模型 judge + 人工抽检）、引用命中率 | `reports/ablation.md` 产出，含 A–D 对比表与结论叙事 |
| R7 | **可复现工程**：README 两条命令跑通；依赖版本锁定；API 成本核算表 | 全新克隆机器（Windows 11）按文档跑通 |

## 约束与风险

**约束**：
- 环境：Windows 11、无 NVIDIA GPU → 模型能力全部经云端 API 调用（已有可用 API key），本地组件（解析、向量库）须 CPU 可跑
- 预算：全量构建 + 一轮完整消融评测的 API 费用 ≤ 几十元人民币（M0 产出精确核算表）
- 工期：2–3 周业余时间（每天 1–3 小时）→ P0 全做 + 部分 P1
- 数据：公开数据集（arXiv cs.CL 为主线；后期小批量中文文字版财报），使用合规
- 语言：中文提问 + 英文文档语料；界面支持中英
- 命名与栈默认（已确认）：项目名 DocLens；开发期轻量调试界面、最终交付正式演示前端；Python 3.12

**风险与缓解**：

| 风险 | 影响 | 缓解 |
|---|---|---|
| 解析质量（图注绑定错、双栏乱序） | 图表题答错 | 解析质检报告 + 抽检机制，及时暴露 |
| 云端 API 可用性/价格变动 | 管道中断 | 嵌入全量缓存、模型名集中配置、备选已验证 |
| 评测集主观性（半自动出题偏差） | 消融结论不可信 | 人工审核 + 双 judge 交叉 + 人工抽检 |
| 时间超支 | P1 砍单 | 里程碑逐个验收，P1 随时可砍不伤 P0 闭环 |
